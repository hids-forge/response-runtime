# Code Of Conduct

This project expects technically rigorous and respectful collaboration.

## Expected Behavior

- Be direct and constructive.
- Critique code and design, not people.
- Keep security discussions precise and evidence-based.
- Respect maintainer decisions about safety boundaries and public release posture.

## Unacceptable Behavior

- Harassment or personal abuse
- Deliberately unsafe guidance disguised as a contribution
- Repeated pressure to weaken default safety posture without technical justification

Maintainers may remove issues, comments, or contributions that violate these rules.
